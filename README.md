# JobTrackr

A fullstack web app to track job applications.

## Stack summary

- Backend: Java 21 + Spring Boot 3 + Spring Data JPA + Spring Security
- Frontend: React + TypeScript + Vite + Tailwind
- Database: PostgreSQL + Flyway
- Testing: JUnit, Testcontainers, Vitest, Playwright
- DevOps: Docker, GitHub Actions, GitHub
